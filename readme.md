# Proyecto ALL SHOES

Este proyecto es una página web dedicada a la venta de zapatillas deportivas y moda urbana. La página incluye una variedad de secciones como inicio, tienda, sobre nosotros y contacto, diseñadas para ofrecer una experiencia de usuario fluida y atractiva.

## Estructura del Proyecto

El proyecto está organizado de la siguiente manera:

- **`/css/`**: Contiene los archivos CSS para estilizar la página.
  - `general.css`: Estilos generales aplicados a toda la página.
  - `header.css`: Estilos específicos para el encabezado.
  - `footer.css`: Estilos específicos para el pie de página.
  - `gallery-item.css`: Estilos para los elementos de la galería.
  - `index.css`: Estilos específicos para la página de inicio.

- **`/html/`**: Contiene las páginas HTML del proyecto.
  - `index.html`: Página principal de inicio.
  - `tienda.html`: Página de la tienda.
  - `about.html`: Página sobre nosotros.
  - `contact.html`: Página de contacto.

- **`/images/`**: Contiene todas las imágenes utilizadas en el proyecto, como logotipos, imágenes de productos, etc.

- **`/js/`**: Contiene los archivos JavaScript para la interactividad de la página.

## Navegación por las Diapositivas

La página de inicio (`index.html`) incluye una sección de diapositivas que muestran diferentes productos destacados. Para navegar por las diapositivas:

1. **Diapositiva 1**: Mike Tair Jordan I
2. **Diapositiva 2**: Mike Jump Vision
3. **Diapositiva 3**: Mike Tair Jordan I (Repetida)

## Cómo Usar

1. Clona el repositorio o descarga el archivo `.zip`.
2. Abre el archivo `index.html` en tu navegador para ver la página de inicio.
3. Navega a través de las diferentes secciones utilizando los enlaces en el encabezado.
